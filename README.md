# Gestor de Clases - instalación sencilla
Esta versión no usa better-sqlite3 y NO necesita Python.
1. Instala Node.js LTS.
2. Abre CMD dentro de esta carpeta.
3. `npm install`
4. `npm start`
5. Abre `http://localhost:3000`
Administrador: admin@clases.local / Admin123!
